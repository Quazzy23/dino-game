ru:

Угадай по роду — это образовательная игра для любителей палеонтологии и биологической систематики. Проверь свои знания родовых и видовых таксонов животных.
Игра создана для популяризации палеонтологических знаний. Основная задача — правильно назвать видовой эпитет для предложенного рода животного.

Установка и запуск:
1. Запустите файл Dino-Game-Setup.exe.
2. Следуйте инструкциям установщика.
3. После установки ярлык игры появится в меню «Пуск» и на рабочем столе.

Ключевые особенности:
1. Три режима игры:
   - Классика: Настройка количества раундов, спокойный темп.
   - Блиц: Проверка скорости. Сколько видов назовешь за ограниченное время?
   - Выживание: Игра на выносливость с ограниченным количеством жизней.
2. Умная проверка: Алгоритмы Левенштейна и Джаро-Винклера позволяют игре прощать опечатки.
3. Кастомизация: Возможность подключать собственные базы данных (.csv/.txt) и папки с изображениями.

en:

Guess by Genus — an educational game for paleontology enthusiasts and biological systematics aficionados. Test your knowledge of genus and species taxa in the animal kingdom.
The game was created to popularize paleontological knowledge. The main objective is to correctly name the species epithet for a given animal genus.

Installation and Run:
1. Run the Dino-Game-Setup.exe file.
2. Follow the installer instructions.
3. After installation, the game shortcut will appear in the Start menu and on desktop.

Key Features:
1. Three Game Modes:
   - Classic: Set the number of rounds, enjoy a relaxed pace.
   - Blitz: Test your speed. How many species can you name within a time limit?
   - Survival: A test of endurance with a limited number of lives.
2. Smart Input Check: The game forgives typos thanks to Levenshtein and Jaro-Winkler distance algorithms.
3. Customization: Ability to connect your own custom databases (.csv/.txt) and image folders.
